Fuel Route Planner

Plans a driving trip between two points in the contiguous USA and chooses where to buy fuel along the way, using the supplied fuel price list.

Plan a trip on the map Try the API Admin

Vehicle

  • {{ mpg }} miles per gallon and a {{ tank_gallons }}-gallon tank, so {{ max_range_miles }} miles of range.
  • Fuel already in the tank is not counted as a purchase.

API

POST {% url 'plan-trip' %}

{
  "start": {"latitude": 34.05223, "longitude": -118.24368},
  "finish": {"latitude": 40.41729, "longitude": -82.90712},
  "initial_fuel_gallons": 30
}

The response has the route, the fuel stops with gallons and cost at each, and the total purchase cost.

Good to know

  • Most station positions are their city's center, not the station itself.
  • Western longitudes are negative.
  • Routes come from openrouteservice and are cached for an hour.
